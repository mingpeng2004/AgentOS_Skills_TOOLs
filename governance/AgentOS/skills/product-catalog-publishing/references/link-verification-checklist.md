# 链接可达性与交付核验清单

发布前逐条跑；每项记录"实测 HTTP 状态 + 字节数"，不写"应该可以"。

## A. 一级页面

| # | 检查 | 判据 | 记录 |
|---|---|---|---|
| A1 | `/` 重定向 | 301 → `/about/`，且 `/about/` 200 | |
| A2 | `/about/` | 200，标题含"公司介绍" | |
| A3 | `/products/` | 200，标题含"产品" | |
| A4 | 页面数 | 一级页面**恰好 2 个**（产品详情与下载为子资源，不计一级） | |

## B. 产品列表

| # | 检查 | 判据 | 记录 |
|---|---|---|---|
| B1 | 条目数 | 与 `products.json` 条目数相等 | |
| B2 | 每条 2 个链接 | 「产品介绍」+「资料下载」都在 | |
| B3 | 无空链接 | 无 `href="#"` / `javascript:void(0)` 冒充功能 | |
| B4 | 无重复 slug | 全局唯一 | |

## C. 详情页（每条都要）

| # | 检查 | 判据 | 记录 |
|---|---|---|---|
| C1 | 可达 | HTTP 200 | |
| C2 | 内容匹配 | 页面标题/型号 == 列表中该条的 title/model | |
| C3 | 下载链接存在 | 指向的 PDF HTTP 200 | |
| C4 | 返回可达 | 有返回上一级/列表的链接 | |

## D. 下载文件（每个都要）

| # | 检查 | 判据 | 记录 |
|---|---|---|---|
| D1 | 可达 | HTTP 200 | |
| D2 | 非空 | `Content-Length > 0` | |
| D3 | 是 PDF | `%PDF-` magic bytes | |
| D4 | **内容可读** | 文本抽取得到型号与中文参数（不只看文件大小） | |
| D5 | 型号一致 | PDF 内型号 == `products.json` 的 model | |

> ⚠️ D4 是最容易漏的：字体选错时 PDF 大小正常但文本抽不出来。

## E. 全站链接

| # | 检查 | 判据 | 记录 |
|---|---|---|---|
| E1 | nav 所有链接 | 全部 200 或明确的 301 | |
| E2 | footer 所有链接 | 全部 200 或明确的 301 | |
| E3 | 页内锚点 | `#id` 有对应元素 | |
| E4 | 外链 | 协议头合法、无 `javascript:` 冒充 | |

## F. 可访问性（需截图复核，静态检查不构成视觉结论）

| # | 检查 | 判据 |
|---|---|---|
| F1 | 标题层级 | h1 → h2 → h3 不跳级 |
| F2 | 链接可读名 | 下载链接文本含"下载" + 型号 |
| F3 | 键盘可达 | Tab 可达所有交互元素，focus 轮廓可见 |
| F4 | 对比度 | 正文 ≥ 4.5:1 |
| F5 | 响应式 | 375px 宽不溢出、不重叠 |

## G. 回滚就绪

| # | 检查 | 判据 |
|---|---|---|
| G1 | 备份存在 | `<site>/.backups/<timestamp>/` 含改前文件 |
| G2 | 备份完整 | 文件数与改动范围一致 |
| G3 | git 可回退 | 仓库工作区状态已记录 |
