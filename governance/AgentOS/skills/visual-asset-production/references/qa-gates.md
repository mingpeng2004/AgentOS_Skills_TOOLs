# 闸门与验收

> 每条闸门都要做**负控制**：改坏一个输入，确认它会报错。��则不知道它是否在工作。

## 1. 文字筛查闸门（底图专属）

### 1.1 为什么需要

生成模型会在展板、表格纸、书本、便签、记录单上**自己写英文**：乱码、错拼、伪手写。
这些字既误导读者，又与矢量层打架。**模型写的字一律重做。**

### 1.2 启发式判据（`scripts/text_screen.py`）

1. 深色像素二值化 → 连通域分析
2. 取「字形尺度」连通域（2K 底图：高 5-70px、宽 3-260px）
3. 按垂直中心聚成「行」
4. 一行内 ≥3 个连通域 → 疑似文字行
5. **排版规律性过滤**（关键）：等高（高变异系数 ≤0.28、高低比 ≤2.3）、
   宽度接近（变异系数 ≤0.95）、间距均匀（变异系数 ≤0.75）

> **只加连通域会误报 41/41** —— 墨线、齿轮、螺丝、电路走线全是"类字形"。
> 加规律性约束后误报降到 17/41，且逐条人工复核确认**全是误报**（木纹/沙粒/砖缝/标尺刻度）。

### 1.3 筛查器不是判据

短标签（每行 2-3 词、间距不规则）会**逃过**筛查器。
**最终仍需逐张目检**（接触印相 + 全分辨率抽看）。

### 1.4 顺带查人脸

风格约束常写 "no visible faces"，但模型不听。**逐张目检时一并看有没有清晰人脸**。
人物只允许背影、手部、局部。

## 2. 逐张目检清单

对每一张底图确认：

- [ ] 内容与主体描述**一一对应**（数量对不对？位置对不对？）
- [ ] **无任何文字/字母/数字/标签/水印**
- [ ] **无清晰人脸**
- [ ] 风格与同批一致（纸底色调、墨线粗细、上色饱和度）
- [ ] 画面留白够放信息带（底部约 24% 不被主体占满）
- [ ] 画幅比例与用途匹配（点子图 16:9 / 横幅 21:9 / 竖版封面 3:4）

## 3. 压缩与体积

| 资产 | 编码 | 目标 |
|---|---|---|
| 实景概念渲染成品图 | **JPEG q94 / 4:4:4**，长边 1700px | 单张 ≤ 0.6 MB |
| 封面主视觉 / 方向横幅 | JPEG q92 / 4:4:4，长边 ≤1700px | 单张 ≤ 0.8 MB |
| 数据图表 | PNG P 模式 256 色 | 见主规范 |
| 动图 | GIF 128 色，最长边 1000px | — |

**改编码格式前必须做像素级差分验证**：

```python
d = np.abs(np.asarray(png).astype(int) - np.asarray(jpg).astype(int))
print(d.max(), d.mean(), (d.max(axis=2) > 24).sum())
```

全图最大差 ≤ 24/255 且无一像素超过 → 视觉无差，才可以换。
（实测 1700×952：PNG 1865 KB → JPEG q94 377 KB，最大差 24，均值 1.02，超阈像素 0。）

**PNG 不能存连续调图像**：同样画面 PNG 1.9MB vs JPEG 0.37MB，差 7 倍。
一个 40 图的报告用 PNG 会让 PPTX 涨到 110MB+。

## 4. 版式约束（放进幻灯片/文档时）

1. **绝不拉伸**：底图原生比例与目标框几乎不可能一致。两种正确做法：
   - `cover`：**等比裁切铺满**（会切掉边缘）
   - `fit`：**按原生比例放置**（留白，不切画面）
   - 直接同时给宽高 = 压扁 = 硬伤
2. **横幅类多场景画面用 `fit`**：21:9 裁成 16:9 会切掉最右一幅场景，宁可留白。
3. **竖版封面单独出图**：16:9 竖裁会切掉主体大半，必须单独生成 3:4。
4. 图注**独立成行**，不要与长标题挤在同一段（超宽时右括号会孤零零掉到第二行）。
5. 图片与文本框**不得重叠**：几何门禁要按真实字体度量算，不能拿名义框高当准。

> **字重陷阱**：量文本宽度时**粗体必须用粗体字库**。雅黑粗体比常规宽 3-6%，
> 差值恰好落在"一行放不放得下"的区间时，估算判过、真机折行 → 副标题压到标题上。
> 几何门禁是**自证**的，只能用真机渲染（PowerPoint COM / LibreOffice 导出 PNG）当独立裁判。

## 5. 资产完整性门禁

与主规范一致：声明数 = 实际用数、media 部件按字节比对、**做负控制**。
