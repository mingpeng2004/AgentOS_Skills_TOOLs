# 两层法：实景概念渲染底图 + 程序化矢量标注层

> 本文是 `VISUAL-ASSET-STANDARD.md` §6 的实现细则。

## 1. 为什么分两层

| | 单独用生成图 | 单独用矢量图 | 两层法 |
|---|---|---|---|
| 形象逼真 | ✅ | ❌ | ✅ |
| 文字可审校 | ❌（模型会自己写字/写错） | ✅ | ✅ |
| 数值不臆造 | ❌ | ✅ | ✅ |
| 部件数量准确 | ❌（模型数不对） | ✅ | ✅ |
| 复核成本 | 逐字读图 | 低 | 低（只审矢量层） |

**结论**：底图只负责"长什么样"，信息层只负责"说了什么"。

## 2. 底图规格

- **分辨率**：2K（长边 2752px 级）；长宽比按用途选 `16:9`（点子图）/ `21:9`（方向横幅）/ `3:4`（竖版封面）
- **构图**：主体居中偏下，上方留白给信息带；一条主线 + 1-3 个关键细节，**不要塞满**
- **数量必须在描述里写死**：`two photoresistors` / `one accelerometer` / `a two-part shell` ——
  模型数不清，描述里要数清
- **位置也要写**：`on the lower left` / `at the far edge` / `in the middle`，
  竖构图要**沿纵深排开**，横向塞满会糊成一团

### 2.1 底图的负向约束（写进 prompt，不是"顺手加一句"）

- 画面中**任何**纸张、卡片、笔记本、屏幕、板面、标签、仪器面板都必须**完全空白、无任何标记**
- 不出现文字、字母、数字、图表、表格、符号、标签、水印
- 不出现清晰人脸（人物只能出现背影/手部/局部）
- 不出现品牌标志

> **实测教训**：只写 "no text" 不够。共同诱因是 prompt 里出现了**可写字的载体**。
> 正确做法是**把载体拿掉** + 叠一句全局约束。
> （2026-10-23 实测：43 张里 7 张带模型自造文字，载体全是展板/表格纸/书本/便签/记录单。）

## 3. 信息层规格

信息层 = 底部信息带，由以下要素组成（从左到右、从上到下）：

| 要素 | 位置 | 内容 | 来源 |
|---|---|---|---|
| 方向色条 | 最左竖条 | 该赛道强调色 | 版式层 token |
| 标题 | 左上 | 图的主标题 | 已审图规格 `title` |
| 副题 | 左下 | 一句限定 | 已审图规格 `sub` |
| 关键部件 | 右上（微标签 + 值） | 画面上的 3-4 个部件短语 | 已审图规格 + OVERRIDE |
| 关键判据 | 右下（微标签 + 值） | 这条图要证明的那件事 | 已审图规格 + OVERRIDE |
| 免责行 | 最下一行 | 「概念渲染示意图，非实物照片」 | 固定 |
| 编号徽标 | 右下角 | dkey 徽标 | 固定 |

**信息带高度** ≈ 画布的 24%（1700×952 画布上为 13.6/56 轴单位）。

### 3.1 竖向分隔细线

标题栏与信息栏之间画一条细线，**位置按实测文字宽度动态计算**：
`左栏右缘 + 空档 > 6 轴单位`才画，避免压字。

> **实测教训**：文字宽度换算若漏了 `/7.2`（磅 → 轴单位），
> 宽度会被放大 72 倍，分隔线永远算不出空档、永远不出现。
> 判别口：量出来的宽度和画出来的宽度对不上，就是单位错了。

### 3.2 OVERRIDE 机制

旧图规格可能是"三种做法对比"，而新画面是"一个真实场景" —— 两者天然对不上。
**不要另起一套口径**，用两张表人工校准并留痕：

- `CRIT_OVERRIDE[dkey] = {zh, en}`：关键判据换成更贴切的那一句
- `LABEL_OVERRIDE[dkey] = {zh, en}`：关键部件短语换成画面里真实存在的部件

> **判别口**：图上画的是什么，标签就得写什么。两者不符就是图文不一致，属硬伤。

## 4. 合成流程

```
raw/<dkey>.png
  → trim_mat()   裁掉生成图四周的纯色纸衬边（有些出图自带白框）
  → cover()      等比裁切铺满目标画布
  → 叠信息带     渐变遮罩 + 实心底 + 细线 + 文字
  → <dkey>_<lang>.jpg
```

**画布**：`10in × 5.6in @ 170dpi = 1700 × 952`（与常见正文版式一致，放进幻灯片不必改版式）。

**双语**：信息层按语言各出一份（`<dkey>_zh.jpg` / `<dkey>_en.jpg`）。
英文版里出现中文标签 = 交付事故。

## 5. 覆写与扩展时注意

- 底图主体描述改一个词 → 整批重生成（5 张/批，2K 出图约 80-110 秒/张）
- 信息层改动**不用**重生成底图，重跑合成即可
- 新增一档尺寸（如竖版封面）→ 单独出一张 `hero_p`，**不要**把 16:9 竖裁
  （16:9 竖裁会切掉工作台大半）
