# 主体描述模板（每图一条，60-110 词）

> 风格由统一模板附加，本文件只写「画什么」。
> 写完先自检：数量写清了吗？位置写清了吗？有没有"可写字的载体"？

## 骨架

```
<一句总述：场景 + 主体 + 环境光>，
<关键部件 1：数量 + 形态 + 位置>，
<关键部件 2：数量 + 形态 + 位置>，
<关键部件 3：数量 + 形态 + 位置>，
<氛围：精确、手工、有学生痕迹>
```

## 自检清单

- [ ] 每个部件都写了**数量**（`two photoresistors` 而非 `photoresistors`）
- [ ] 每个部件都写了**位置**（`on the lower left` / `at the far edge` / `in the middle`）
- [ ] 没有"可写字的载体"（展板 / 表格 / 书本 / 便签 / 记录单 / 笔记 / 清单）
      → 出现就改成 `blank unmarked ...`，或直接不写
- [ ] 人物只写背影 / 手部 / 局部，不写正脸
- [ ] 竖构图（3:4）的物体**沿纵深排开**，不要横向塞满

## 正例

```
a small sensor station clamped to the edge of a wooden school desk, a red infrared
distance sensor facing outward over the desktop, a flat black motion module lying
next to it, a short strip of small addressable LEDs glowing green amber and red
along the desk edge, a blue microcontroller board with a USB cable running down
the clamp, a softly blurred empty classroom background of bare chairs, warm
afternoon light across the desktop
```

## 反例（会踩坑）

| 反例 | 后果 | 正解 |
|---|---|---|
| `a display board listing the five steps` | 模型自己写英文标签 | `a plain unmarked corkboard` |
| `a notebook with the teacher's notes` | 伪手写 | `a closed plain notebook with a blank unmarked cover` |
| `a printed comparison table` | 表格 + 乱码列标题 | `a plain empty wooden board` |
| `some sensors` | 数量随机 | `three sensors` |
| `a student drawing a city` | 清晰人脸 | `a student seen strictly from behind ... no face no eyes no profile` |
